TOP COMMUNICATION — FICHIERS DU SITE

1. index.html : page du site
2. style.css : design vert #3BB293, noir et blanc
3. script.js : menu mobile et formulaire de contact

SUR LA PAGE GITHUB « UPLOAD FILES » :
- Clique sur « Choisissez vos fichiers ».
- Sélectionne index.html, style.css et script.js (tu peux aussi ajouter README.txt).
- Important : sélectionne les fichiers eux-mêmes, pas le fichier ZIP.
- Descends à « Valider les modifications » et clique sur « Commit changes » / « Valider les modifications ».
- Ensuite ouvre Settings > Pages, choisis Deploy from a branch, branche main, dossier /(root), puis Save.

Avant de partager le site, remplace l’adresse e-mail provisoire dans script.js et complète le numéro WhatsApp dans index.html.
